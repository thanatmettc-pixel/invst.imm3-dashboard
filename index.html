    📤 ส่งออกไฟล์
    1เลือกสิ่งที่จะส่งออก
    2รูปแบบไฟล์
    3ขนาดกระดาษ / สไลด์
    4ความละเอียด
    5ปลายทางการบันทึก
    ไม่มีหน้าต่างให้เลือกโฟลเดอร์? ตั้งค่าเบราว์เซอร์ให้ถามตำแหน่งทุกครั้ง (ทำครั้งเดียว)
    • Brave: ☰ → การตั้งค่า (Settings) → ดาวน์โหลด (Downloads) → เปิด “ถามตำแหน่งที่จะบันทึกไฟล์แต่ละไฟล์ก่อนดาวน์โหลด” (Ask where to save each file before downloading) (พิมพ์ brave://settings/downloads ในช่องที่อยู่)
    • Chrome: ⋮ → การตั้งค่า → ดาวน์โหลด → เปิด “ถามตำแหน่งที่จะบันทึกไฟล์แต่ละไฟล์ก่อนดาวน์โหลด” (chrome://settings/downloads)
    • Edge: ⋯ → การตั้งค่า → ดาวน์โหลด → เปิด “ถามฉันว่าต้องทำอะไรกับการดาวน์โหลดแต่ละครั้ง” (edge://settings/downloads)
    • Firefox: ☰ → การตั้งค่า → ทั่วไป → ไฟล์และแอปพลิเคชัน → “ถามคุณเสมอว่าจะบันทึกไฟล์ที่ใด”
    • Safari: การตั้งค่า → ทั่วไป → ตำแหน่งที่ดาวน์โหลดไฟล์ → “ถามสำหรับการดาวน์โหลดแต่ละครั้ง”

    บางมุมมอง (เช่น แอปฝังในหน้าเว็บ) เบราว์เซอร์ไม่อนุญาตให้เปิดหน้าต่างเลือกโฟลเดอร์โดยตรง ระบบจะส่งไฟล์ไปที่ตัวดาวน์โหลดของเบราว์เซอร์แทน — เมื่อเปิดการตั้งค่าข้างต้น เบราว์เซอร์จะถามโฟลเดอร์ปลายทางให้ทุกครั้ง

    🗄️ ถังสำรองข้อมูล

    เก็บสำเนาข้อมูลทั้งชุดไว้ในเบราว์เซอร์เครื่องนี้ (สูงสุด 30 ชุด) — ระบบเก็บให้อัตโนมัติวันละครั้ง และทุกครั้งก่อนลบ นำเข้า กู้คืน หรืออัปเดตจาก Google Sheets · ควรส่งออกเก็บเป็นไฟล์ด้วยเป็นระยะ

    • Chrome: ⋮ → การตั้งค่า (Settings) → ดาวน์โหลด (Downloads) → เปิด “ถามตำแหน่งที่จะบันทึกไฟล์แต่ละไฟล์ก่อนดาวน์โหลด”
